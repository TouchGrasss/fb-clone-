# FB Clone

This project is a simple Facebook clone created while learning and practicing Git and GitHub.

## 📌 About the Project

The main purpose of this project is to understand how Git and GitHub work in a real project. While building this project, I practiced creating a repository, tracking changes, committing code, and pushing the project to GitHub.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 What I Learned

- How to create a Git repository
- How to initialize Git using `git init`
- How to track files using `git add`
- How to create commits using `git commit`
- How to connect a local project with GitHub
- How to push code to a remote repository
- How to manage project changes using Git

## 🚀 Features

- Facebook-inspired user interface
- Simple and responsive layout
- Basic frontend structure
- Practiced Git version control
